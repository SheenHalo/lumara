# Lumara 功能文档

本文档记录 Lumara 当前已经实现的功能。更细的 HTTP 接口字段见 [backend-api.md](backend-api.md)，线上部署细节见 [deployment.md](deployment.md)。

## 功能概览

Lumara 的核心模式是“服务器先下载，浏览器再取回”：下载任务在服务器端运行，网页只负责创建任务、查看进度、浏览结果和下载 ZIP。这样可以减少本地长时间直连 NASA SDO 归档站点带来的不稳定。

当前已实现：

- Web 下载工作台：创建下载任务、查看任务列表、查看进度、删除已完成任务记录、按任务浏览图片。
- 服务器下载：按日期范围、分辨率、图片类型、数量限制和并发数下载 NASA SDO 图片。
- 图片浏览：缩略图网格、分页、原图弹窗、任务图片独立滚动。
- ZIP 取回：下载当前选择的图片，或为整个任务目录创建服务器端异步压缩任务并显示进度。
- 图片类型页：展示 SDO 常用图片类型、中文说明和 NASA 最新 512 示例图。
- 后端接口：提供健康检查、选项、下载任务、图片查询、缩略图、原图和 ZIP 相关接口。
- 命令行下载器：保留 `cmd/lumara-sdo`，可在无前端场景下直接下载。

## Web 工作台

### 新建下载任务

网页顶部的“新建下载任务”表单支持：

| 选项 | 说明 |
| --- | --- |
| 开始日期、结束日期 | 下载闭区间内的每日图片 |
| 分辨率 | 支持 `512`、`1024`、`2048`、`4096` |
| 图片类型 | 支持常用 AIA 和 HMI 通道 |
| 数量限制 | `0` 表示不限制；适合先做小范围测试 |
| 并发 | Web API 最大限制为 `16` |
| 校验已存在 | 跳过本地文件前，用远端 `Content-Length` 校验大小 |

任务提交后，服务端会异步处理，前端会定时刷新任务列表和当前任务图片。

### 下载任务列表

任务卡片展示：

- 日期范围、分辨率和图片类型。
- 任务状态：排队、运行、完成、失败、取消。
- 下载进度条。
- 已下载、已跳过、失败数量。
- 当前任务消息。

已结束任务可以删除记录。删除只会移除任务历史，不会删除服务器上的图片、缩略图或 ZIP 文件。

后端已经提供 `POST /api/downloads/{id}/cancel` 取消接口；当前 Web 界面主要覆盖创建、查看和删除已结束任务。

### 任务图片浏览

选择任务后，右侧图片区展示该任务对应的图片：

- 默认请求缩略图，减少浏览器加载压力。
- 点击图片或查看按钮打开原图弹窗。
- 图片区域独立滚动，页面布局保持固定。
- 默认每页展示 12 张图片。
- 翻页时会清空当前选择，避免跨页误下载。

缩略图由后端第一次请求时生成，缓存到 `.thumbnails` 目录。缩略图生成失败时，接口会回退返回原图。

### ZIP 下载

Web 当前有两种取回方式：

| 方式 | 行为 | 适用场景 |
| --- | --- | --- |
| 下载已选 | 调用同步 ZIP 接口，直接打包当前选中的图片 | 少量图片 |
| 下载整个任务目录 | 服务器创建后台压缩任务，前端轮询进度，完成后下载 ZIP | 大任务、整批取回 |

整个任务目录的 ZIP 会生成在 `.archives` 目录中。压缩任务状态保存在内存里，服务重启后旧压缩任务状态不可查询；已经生成的 ZIP 文件仍会留在磁盘上。

## 服务端下载能力

`cmd/lumara-web` 内置下载器会从 NASA SDO browse archive 读取每日目录：

```text
https://sdo.gsfc.nasa.gov/assets/img/browse/YYYY/MM/DD/
```

下载过程支持：

- 解析 NASA 目录中的 `.jpg` 文件。
- 按分辨率和图片类型过滤。
- 多日期范围下载。
- 并发下载。
- 网络请求失败重试和指数退避。
- 使用 `.part` 临时文件断点续传。
- 已存在文件复用。
- 可选远端大小校验。
- 下载任务历史持久化到 `.lumara-jobs.json`。

如果启用“校验已存在”，本地文件小于远端大小时会转成 `.part` 继续下载；本地文件大于远端大小时会保留为 `.bad`，然后重新下载。

## 图片与数据目录

Web 服务通过 `--output` 指定图片保存目录，默认是 `downloads`。

图片路径格式：

```text
downloads/2026/05/17/512/0304/20260517_000854_512_0304.jpg
```

内部文件和目录：

```text
downloads/.lumara-jobs.json       # 下载任务记录
downloads/.thumbnails/            # 缩略图缓存
downloads/.archives/              # 服务器端生成的 ZIP 包
*.jpg.part                        # 未完成的断点续传文件
*.jpg.bad                         # 校验异常后保留的旧文件
```

图片文件接口会限制路径必须位于 `--output` 目录下，防止绝对路径和 `..` 越界访问。

## 图片类型

前端顶部提供“图片类型”页面。该页面是纯前端展示页，不依赖后端接口，会展示每个类型的编号、英文名、中文说明和 NASA 最新公开 512 分辨率示例图。

| 类型 | 英文名 | 说明 |
| --- | --- | --- |
| `0304` | Chromosphere | 色球层，常用来观察日珥、耀斑和太阳边缘活动 |
| `0171` | Quiet Corona | 宁静日冕，适合观察较安静的日冕环结构 |
| `0193` | Corona | 日冕，适合观察日冕洞、热等离子体和较大尺度结构 |
| `0211` | Active Regions | 活跃区，适合观察高温活跃区和磁场活动区域 |
| `0094` | Hot Flares | 高温耀斑，适合观察非常热的耀斑区域 |
| `0131` | Flare Plasma | 耀斑等离子体，适合观察强耀斑和极高温等离子体 |
| `0335` | Active Corona | 活跃日冕，适合观察活跃日冕区域和环状结构 |
| `1600` | Transition | 过渡区，观察光球层到日冕之间的过渡区域 |
| `1700` | Surface | 太阳表面，接近可见光表面，适合观察表面纹理 |
| `HMIIF` | Sunspots | 太阳黑子，白光强度图，适合观察太阳黑子 |
| `HMIBC` | Magnetic Field | 磁场图，显示太阳表面磁场正负极分布 |

支持分辨率：

```text
512, 1024, 2048, 4096
```

## Go 命令行下载器

`cmd/lumara-sdo` 是保留的命令行下载器，适合无前端或脚本化场景。

构建：

```powershell
go build -o build\lumara-sdo.exe .\cmd\lumara-sdo
```

示例：

```powershell
.\build\lumara-sdo.exe 2026-05-17 --resolutions 512 --channels 0304 --limit 3
.\build\lumara-sdo.exe 2026-05 --resolutions 512 --channels 0304 --dry-run
.\build\lumara-sdo.exe --from 2026-01-01 --to 2026-05-19 --all --estimate
```

CLI 支持：

- 目标日期可以是 `YYYY`、`YYYY-MM` 或 `YYYY-MM-DD`。
- 也可以使用 `--from` 和 `--to` 指定闭区间。
- `--resolutions`、`--channels` 过滤常用图片。
- `--all` 下载目录内所有 `.jpg`。
- `--estimate` 只估算文件数和目录列出的大小。
- `--dry-run` 只列出将要处理的文件。
- `--flat` 将文件直接保存到输出目录，不按日期分层。
- `--workers`、`--retries`、`--timeout`、`--retry-delay`、`--chunk-size` 调整下载行为。

## 当前限制和注意事项

- 当前服务没有登录鉴权。部署到公网时，建议放到内网、加反向代理鉴权，或配置防火墙白名单。
- 大范围下载会消耗大量磁盘空间，建议先用小日期范围和 `limit` 测试。
- `.archives` 中的压缩包不会自动清理，长期运行时建议定期清理旧 ZIP。
- Web 界面的“下载已选”适合少量图片；整任务下载请使用异步压缩。
